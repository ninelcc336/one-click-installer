# 安装器入口与返回行为优化设计

## 目标

让欢迎页明确表达“进入安装流程”，并修复从安装内容选择页返回后错误显示检测失败的问题。

## 行为设计

- 欢迎页的主按钮文案改为“进入安装流程”，因为点击它只会进入预检和安装内容选择页，不会立即执行安装。
- 预检页继续使用“开始安装”，因为此按钮才真正启动下载和安装流程。
- 从预检页返回欢迎页时保留 `preflight`、检测结果和已选择应用，不重新标记为检测失败，也不清空已完成的检测状态。
- 用户再次点击“进入安装流程”时直接回到已有预检结果，不重复调用检测命令。

## 测试

- 欢迎页显示“进入安装流程”，不显示“开始安装”。
- 预检页仍显示“开始安装”。
- 有预检数据的欢迎页显示检测摘要，而不是“暂时无法检测电脑状态”。
